\chapter{Premiers pas avec Grisbi\label{start}}


\section{Installation\label{start-install}}

Grisbi est disponible en version stable, en version instable et en version de développement pour Windows, Linux et macOS.

Sur le site \lang{Sourceforge.net}, vous trouverez la \lang{version stable}\footnote{\urlSourceForgeGrisbiStable} et \lang{la version instable}\footnote{\urlSourceForgeGrisbiInstable}.

La version de développement est, elle, disponible sur \lang{GitHub}\footnote{\urlGitHubGrisbi}

\vspace{2mm}
\noindent
\Attention{}: il est déconseillé d'utiliser la version instable ou de développement avec votre fichier de compte habituel, sous peine de possibles pertes de données en cas de dysfonctionnement.

\subsection{Version stable\label{start-install-stable}}

Téléchargez la dernière version stable pour votre système d'exploitation.

\Note{}: vous y trouverez en particulier des instructions d'installation pour le système macOS.

\subsubsection{Windows\label{start-install-stable-windows}}

Windows 7 et 8 ne sont plus supportés ainsi que les processeurs 32bit.

\begin{enumerate}
	\item cliquez sur le fichier de la forme \frquote{Grisbi-64bit-version-setup.exe} précédemment téléchargé;
	\item une fenêtre avec un avertissement de sécurité s'ouvre, vous informant que l'éditeur n'a pas pu être vérifié; cliquez sur \menus{Exécuter};
	\item sélectionnez votre langage dans la liste déroulante puis cliquez sur \menus{OK};
	\item la fenêtre de bienvenue de l'installation s'ouvre; cliquez sur \menus{Suivant};
	\item la fenêtre suivante vous demande si vous acceptez la \gls{Licence Publique Generale GNU} (GNU General Public License) Version 2; cliquez sur \menus{J'accepte};
	\item Grisbi vous propose ensuite un dossier d'installation par défaut, que vous pourrez modifier; puis cliquez sur \menus{Installer};
	\item en fin d'installation, la dernière fenêtre vous propose de:
		\begin{itemize}
			\item \frquote{Lancer Grisbi 64bit} (par defaut) ou non en décochant la case;
			\item \frquote{Créer une icône sur le bureau}  (par defaut) ou non en décochant la case;
		\end{itemize}
	\item cliquez sur \menus{Fermer}.
	\item vous pourrez ensuite paramétrer Grisbi (voir la section \vref{start-first} \menus{Assistant au premier démarrage}).
\end{enumerate}

\subsubsection{Linux\label{start-install-stable-linux}}

\paragraph{Debian/Ubuntu et dérivés}\mbox{}		%\mbox{}= to allow a line break

La dernière version stable est disponible dans les dépôts; vous pourrez l'installer avec votre gestionnaire de paquets en recherchant \frquote{Grisbi}.

Si vous téléchargez les deux (2) fichiers d'\gls{extension} \frquote{.deb}, vous pourrez les installer avec la commande suivante:

%\begin{verbatim}
\cmds{sudo apt install ./grisbi\_*\_amd64.deb ./grisbi-common\_*\_all.deb}
%\end{verbatim}

\paragraph{Autres distributions Linux}\mbox{}		%\mbox{}= to allow a line break

La dernière version stable est disponible pour Mageia, openSUSE, Solus.

\paragraph{Flatpak}\mbox{}		%\mbox{}= to allow a line break

Grisbi est également disponible en version Flatpak sur \lang{Flathub}\footnote{\urlFlatpakGrisbi}.

\paragraph{Fichiers sources}\mbox{}		%\mbox{}= to allow a line break

Vous pouvez aussi installer Grisbi à partir des sources, le fichier \frquote{grisbi-version.tar.xz}, précédemment téléchargé.

Il vous faudra, au préalable, avoir installé (sous Debian/Ubuntu):
\begin{itemize}
	\item meson (outil de compilation),
	\item libglib2-dev,
	\item libgtk-3-dev et libgtk-3-bin
	\item libgsf-1-dev,
	\item libgoffice,
	\item libofx-dev (optionnel),
	\item libssl-dev (optionnel) pour le chiffrement du fichier,
	\item libxml2-dev (optionnel).
\end{itemize}

Puis pour compiler et installer Grisbi, procédez comme suit:

\begin{enumerate}
	\item décompressez le fichier \frquote{grisbi-version.tar.xz},
	\item allez dans le dossier contenant le fichier décompressé et exécutez, dans l'ordre, les commandes suivantes:
		\begin{itemize}
		\item \cmds{meson setup builddir -{}-prefix=/dossier\_où\_installer\_grisbi}
		% using -{}- to break ligature with \texttt{}(=\cmds{}), if not, prints -prefix=...
		\item \cmds{meson compile -C builddir}
		\item \cmds{meson install -C builddir}
		\end{itemize}
	\item vous trouverez l'exécutable dans le dossier \frquote{/dossier\_où\_installer\_grisbi/bin}.
\end{enumerate}

\subsubsection{macOS\label{start-install-stable-macos}}

Pour installer Grisbi sous macOS, veuillez vous référer à la page de téléchargement\footnote{\urlSourceForgeGrisbiStable} à partir de la version 3.90.0.


\subsection{Version instable\label{start-install-instable}}

Des versions instables sont également disponibles sur \lang{Sourceforge.net}\footnote{\urlSourceForgeGrisbiInstable} et sont installables de la même façon que les versions stables pour tous les systèmes d'exploitation (voir la section \vref{start-install-stable}).



\subsection{Version de développement\label{start-install-devel}}

La version de développement est disponible sur \lang{GitHub}\footnote{\label{fn:github}\urlGitHubGrisbi}.

Pour plus d'information, reportez-vous aux pages \lang{Wiki}\footnote{\urlGitHubGrisbiWiki} sur GitHub.

Sous Debian/Ubuntu, il vous faudra, au préalable, avoir installé:
\begin{itemize}
	\item meson (outil de compilation),
	\item libglib2-dev,
	\item libgtk-3-dev et libgtk-3-bin,
	\item libgsf-1-dev,
	\item libgoffice,
	\item libofx-dev (optionnel),
	\item libssl-dev (optionnel) pour le chiffrement du fichier,
	\item libxml2-dev (optionnel).
\end{itemize}

Il vous faudra ensuite récupérer les sources sur \lang{GitHub}\footref{fn:github} avec la commande suivante:

\cmds{git clone https://github.com/grisbi/grisbi.git}

Puis dans le dossier de téléchargement des sources, exécutez, dans l'ordre, les commandes suivantes:
\begin{itemize}
	\item \cmds{meson setup builddir -{}-prefix=/dossier\_où\_installer\_grisbi}
	% using -{}- to break ligature with \texttt{}(=\cmds{}), if not, prints -prefix=...
	\item \cmds{meson compile -C builddir}
	\item \cmds{meson install -C builddir \&\& rm -r builddir}
\end{itemize}

L'exécutable est alors disponible dans le dossier \frquote{/dossier\_où\_installer\_grisbi/bin}.


\section{Assistant au premier démarrage\label{start-first}}


Après l'installation de Grisbi et au premier lancement du logiciel, celui-çi vous aidera avec trois assistants consécutifs:
\begin{enumerate}
	\item Le premier assistant \frquote{Bienvenue dans Grisbi !}, (qui ne s'affichera qu'une seule fois, au premier lancement), vous aide à configurer l'application. Il comprend deux étapes, dont la deuxième qui concerne la gestion du \indexword{fichier de comptes}\index{fichier de comptes} (chargement et enregistrement automatiques, chiffrement et copies de sauvegarde).

\begin{figure}[htbp]
	\begin{center}
		\includegraphics[width=0.98\textwidth]{image/screenshot/start_first_launch}
	\end{center}
	\caption{Configuration initiale du fichier de comptes.}
	\label{start_first_launch}
\end{figure}

Il est conseillé de cocher les options:
	\begin{itemize}
		\item Chargement automatique du dernier fichier consulté;
		\item Enregistrer automatiquement en fermant;
		\item Effectuer une copie de sauvegarde avant d'enregistrer les fichiers (coché par défaut).
	\end{itemize}
\end{enumerate}

\Attention{}: les développeurs de Grisbi vous recommandent de ne pas utiliser l'option \menus{Chiffrer le fichier Grisbi} pour les raisons suivantes: 
	\begin{itemize}
		\item il n’existe aucune méthode pour récupérer un fichier chiffré dont on a perdu le mot de passe;
		\item Pour une raison inconnue, l’utilisation de cette option sous Windows peut rendre le fichier de comptes totalement inutilisable.
	\end{itemize}
Néanmoins, si vous l'utilisez, il est recommandé de faire régulièrement des sauvegardes du fichier non chiffré.

\vspacepdf{3mm}
\begin{enumerate}[resume]
	\item Le deuxième assistant \frquote{Bienvenue dans Grisbi !} (ou plus tard \frquote{Aide à la création d'un nouveau fichier de comptes}), qui suit automatiquement le premier, comprend six étapes qui vous aiderons à la création du \indexword{fichier de comptes}\index{fichier de comptes}. 
	\item Puis vient automatiquement le troisième assistant \frquote{Créer un nouveau compte} qui permet de créer le premier compte et qui est décrit en détail dans la section \ref{start-newfile} ci-dessous.
\end{enumerate}
À tout moment vous pouvez sortir de n'importe quel assistant par le bouton \menus{Annuler}.

Si vous ne voulez pas utiliser l'assistant premier démarrage, vous pouvez à la
place utiliser un fichier exemple (voir la section \ref{start-example} ci-dessous).

\section{Création d'un nouveau fichier de comptes\label{start-newfile}}


La première fois que vous utiliserez Grisbi, vous devrez d'abord créer un \indexword{fichier
de comptes}\index{fichier de comptes} qui contiendra votre comptabilité. L'\gls{extension} de ce fichier sera \file{.gsb} et son nom \file{nom-de-votre-fichier.gsb}. 

Immédiatement après, il vous faudra créer au minimum un compte (bancaire, de caisse, de passif ou d'actif, décrits au chapitre \vref{accounts} \menus{Gestion des comptes}), et par la suite quelques autres comptes (comptes courants, d'épargne, de crédit, éventuellement un compte d'espèces et quelques comptes de transition) qui contiendront leurs opérations respectives. 

Pour une gestion familiale, vous n'aurez normalement qu'un seul fichier de comptes, car cela permet tous les échanges entre vos différents comptes. Si vous gérez une association, ou une autre famille sans rapport comptable avec la première, vous créerez un autre fichier de comptes, qui portera un autre nom \file{nom-de-votre-deuxième-fichier.gsb}. Ainsi les \indexword{entités comptables}\index{entité comptable} resteront bien séparées.

Autrement dit, l’ensemble des comptes de votre foyer est enregistré dans un fichier créé par Grisbi,
et l’ensemble des comptes de votre association l’est dans un autre fichier créé par Grisbi.

\vspacepdf{3mm}
\Note{}: pour les plus curieux, le fichier Grisbi est au format \gls{XML}\index{XML}, et la structure et l'organisation des données est disponible sur le site de \lang{Sourceforge.net}\footnote{\urlSourceForgeDocumentationFormat{}}.

\section{Enregistrement de votre fichier de comptes\label{start-save}}


Vos opérations ne sont pas écrites au fur et à mesure de leur saisie comme elles peuvent l'être dans d'autres logiciels; vous devez donc enregistrer votre fichier de comptes avant de quitter. N'ayez crainte, Grisbi vous prévient si vous ne l'avez pas fait. 

Vous pouvez configurer les options d'enregistrement du fichier de comptes dans le menu \menus{Éditer - Préférences}, voir le paragraphe \vref{setup-general-files-manage}, \menus{Gestion des fichiers de comptes}.


\section{Import à partir d'un autre logiciel de comptabilité personnelle}

Voir la section \vref{move-import-importinit} pour importer des fichiers de compte d'un autre logiciel dans Grisbi. Pour le moment, Grisbi supporte les formats \gls{Gnucash}, \gls{OFX}, \GLS{CSV} et \GLS{QIF}.
